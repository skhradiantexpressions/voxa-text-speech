# 🎈 How to Run Voxa (The Easy Way!)

Hello! Here is how you start your new voice app. Follow these 4 little steps:

### 1️⃣ Go to the App Folder
Open your **Terminal** and paste this magic spell:
```bash
cd "/home/shussain/projects/outreach-dashboard/.agent/skills/Voxa (text-speech)"
```

### 2️⃣ Get the Tools Ready
Paste this command and hit **Enter**. It might take a little nap (wait a few seconds):
```bash
npm install
```

### 3️⃣ Start the Engine! 🚀
Now type this and hit **Enter**:
```bash
npm run dev
```

### 4️⃣ Open the App
You will see a link like `http://localhost:5173`. **Click it!**
Your app will pop up in the browser. 

---
**🎤 To use it:** Click the big microphone and start talking!
**⬇️ To install it:** Look for a little "Install" button or icon in your address bar.
